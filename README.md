# Everyday Things, Two Lines, Longer Run — make.fun entry

Entry for the make.fun competition
[u-suga-everyday-things-two-lines-longer-run-f8734479](https://make.fun/c/u-suga-everyday-things-two-lines-longer-run-f8734479)
("Everyday Things, Two Lines, Longer Run").

`main.py` (Python standard library only) writes a two-line text to
`/output/entry.txt`:

- Line 1 explains one everyday object — a zipper — to a 10-year-old in a
  single vivid sentence built on one analogy.
- Line 2 explains, in one sentence, why the analogy works: what it maps
  and what it leaves out.

Run it with `python3 main.py`.
